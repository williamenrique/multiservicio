LISTO A. Estabilidad y Seguridad (Cimientos)
    Middleware CSRF Global: Actualmente, el token se valida en el Login, pero no en todas las peticiones POST/PUT/DELETE. Implementar una verificación automática protegería todo el sistema de ataques de falsificación.
    Manejador Global de Excepciones: Crear un "Exception Handler" centralizado para que cualquier error (BD, Stock, Permisos) devuelva siempre un JSON estandarizado al frontend, evitando que el sistema "muera" en silencio.
    Refactorización de Servicios: Mover el 100% de la lógica de negocio que aún queda en los modelos (como el cálculo de utilidad o stock) hacia clases de Servicio, dejando los modelos solo para consultas SQL puras.

B. Inteligencia de Negocio (Reportes y Finanzas)
Reporte de Cartera por Edades: Una vista que clasifique las deudas de clientes en: 0-15 días, 16-30 días y +30 días, facilitando la gestión de cobranza.
Análisis de Rentabilidad por Servicio: Calcular cuánto se gana realmente en mano de obra vs. repuestos, permitiendo saber qué servicios son los más rentables del taller.
Cierre de Caja Ciego: Implementar un proceso donde el cajero debe ingresar cuánto dinero físico tiene antes de que el sistema le muestre cuánto "debería" haber (evitando ajustes manuales malintencionados).

C. Experiencia del Cliente (Fidelización)
Notificaciones Automáticas vía WhatsApp/Email: Integrar una API para notificar al cliente automáticamente cuando su vehículo pase de "En Reparación" a "Listo para Entrega".
Portal de Consulta Externa: Una página pública (sin login) donde el cliente, solo con su placa y un código, pueda ver el estado actual de su orden de servicio y fotos del progreso.
D. Optimización Operativa (Taller e Inventario)
Asignación de Mecánicos y Tiempos: Poder asignar mecánicos específicos a cada ítem de una orden de servicio para medir la productividad del personal.
Escaneo de Código de Barras: Adaptar el buscador de facturación e inventario para que acepte entradas de escáner, acelerando la venta de repuestos en mostrador.
Gestión de Archivos de Vehículos: Permitir subir fotos del estado en que llega el vehículo (evidencia visual) directamente en la Orden de Servicio.
3. Diagnóstico Técnico Actual
Punto Fuerte: El uso de transacciones SQL (beginTransaction, commit) en los modelos de proveedores y facturación garantiza que la base de datos nunca quede en un estado inconsistente si algo falla a mitad de proceso.
Punto a Mejorar: Hay una mezcla de lógica de presentación (generación de HTML vía JS) que se está volviendo extensa. Podríamos considerar una pequeña refactorización de componentes JS para que sean más reutilizables.
