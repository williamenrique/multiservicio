 25. REGLAS DE NEGOCIO IMPORTANTES
================================================================================

1. CONTROL DE ACCESO:
   - Roles: ADMINISTRADOR, MECANICO, AYUDANTE, VENDEDOR
   - ADMINISTRADOR: acceso total
   - MECANICO: taller, historial, perfil
   - VENDEDOR: facturación, venta mostrador, clientes
   - AYUDANTE: limitado a taller

2. FLUJO DE ÓRDENES:
   RECIBIDO → DIAGNOSTICANDO → EN_REPARACION → LISTO → ENTREGADO
   Cualquier estado puede ir a CANCELADO

3. FACTURACIÓN:
   - Una orden puede tener múltiples facturas (parciales)
   - Borradores guardados antes de facturar
   - IVA configurable por empresa

4. INVENTARIO:
   - Stock mínimo configurable por producto
   - Alerta visual cuando stock < mínimo
   - Kardex obligatorio para cada movimiento

5. SEGURIDAD:
   - CSRF Token en todos los formularios
   - Rutas protegidas por middleware (AuthGuard, RoleGuard)
   - Auditoría de todas las operaciones CRUD
